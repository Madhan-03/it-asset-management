# IT Asset Management System

A comprehensive IT asset management system with authentication, asset tracking, employee management, allocations, maintenance requests, and reporting.

## Features
- 🔐 User Authentication (Login/Register)
- 📦 Asset Management (CRUD)
- 👥 Employee Management
- 🔄 Asset Allocation & Returns
- 🔧 Maintenance Requests
- 📊 Reports Generation (PDF)
- 🔔 Notifications System
- 🌙 Dark/Light Theme
- 👤 Profile Management
- 📱 Responsive Design

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: MongoDB Atlas
- **Authentication**: JWT
- **PDF Generation**: jsPDF
